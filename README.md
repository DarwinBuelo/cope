# Front-End CSS Demo Project

This project is a collection of small front-end experiments and learning demos focused on responsive layout, design systems, and comparison between plain HTML/CSS, Bootstrap, and Tailwind CSS.

## Overview

The workspace includes:

- Plain HTML/CSS examples in [html/](html/)
- Bootstrap-based demos in [bootstrap/](bootstrap/)
- Tailwind-based demos in [tailwind/](tailwind/)
- Visual comparison notes and seminar materials in the root folder

## Project Structure

- [html/basic.html](html/basic.html) — simple HTML/CSS structure and layout practice
- [html/index.html](html/index.html) — dashboard-style page built with custom CSS
- [html/layout.css](html/layout.css) — styling for the custom HTML layout
- [bootstrap/index.html](bootstrap/index.html) — Bootstrap demo page
- [tailwind/index.html](tailwind/index.html) — Tailwind demo page
- [demo.html](demo.html) — general demo page
- [bootstrap-seminar-demo.html](bootstrap-seminar-demo.html) — Bootstrap seminar example
- [tailwind-seminar-demo.html](tailwind-seminar-demo.html) — Tailwind seminar example
- [TAILWIND vs BOOTSTRAP.md](TAILWIND%20vs%20BOOTSTRAP.md) — comparison notes
- [tailwind-bootstrap-comparison.md](tailwind-bootstrap-comparison.md) — comparison summary
- [beginner-bootstrap.md](beginner-bootstrap.md) — beginner-friendly Bootstrap guide
- [beginner-tailwind.md](beginner-tailwind.md) — beginner-friendly Tailwind guide

## Learning Goals

This project is designed to help with:

- understanding semantic HTML
- building responsive layouts with CSS
- comparing utility-first styling vs component-based frameworks
- practicing modern front-end UI concepts

## How to Run

Because these are static HTML/CSS demos, you can open the files directly in a browser.

### Option 1: Open directly

Open any HTML file in your browser, such as:

- [html/index.html](html/index.html)
- [bootstrap/index.html](bootstrap/index.html)
- [tailwind/index.html](tailwind/index.html)

### Option 2: Serve locally

From the project root, run:

```bash
python3 -m http.server 8000
```

Then open:

```text
http://localhost:8000/
```

## Notes

- Some pages use CDN-based libraries, so an internet connection is required when viewing them in the browser.
- This is a study/demo project, not a production application.
- The examples are useful for learning and experimenting with UI design patterns.

## Recommended Next Steps

- Review the Bootstrap and Tailwind notes before exploring the demos.
- Practice customizing the styles in the CSS files.
- Build a small page of your own by combining the ideas from the plain HTML and framework examples.
